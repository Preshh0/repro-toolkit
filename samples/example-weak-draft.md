# Churn prediction

## Abstract
We predict customer churn with a gradient boosting model.

## Introduction
Churn is costly. We built a model.

## Methods
We use gradient boosting with 300 trees and depth 6. Features were cleaned and normalised. Training used python and scikit-learn.

## Results
The model reached accuracy 87% and F1 0.81 on the test set.

## Discussion
Results are promising. The trained model weights are available on request. The code will be released upon acceptance. Our data is proprietary and cannot be shared.

## Conclusion
Good results.
